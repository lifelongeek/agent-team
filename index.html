어떤 애플리케이션인가요

lifelongeek agent team은 개발자 본인이 혼자 쓰려고 만들어 개인 컴퓨터에서 직접 운영하는 채팅 애플리케이션입니다. 역할이 다른 여섯 개의 에이전트가 각자의 대화방에서 일상 업무를 돕습니다.

  • 실장님 — 일정과 메일을 종합한 하루 브리핑, 다른 에이전트에게 업무 위임
  • 돈나무 — 개인 자산 기록 정리와 시장 자료 요약
  • 도비 — 할 일과 알림 관리
  • 의사양반 — 건강 기록 정리
  • 짹짹이 — 관심 주제 소식 모음
  • 꼼지락 — 취미·학습 기록

웹 앱(PWA) 형태로, 개발자의 개인 기기에서만 접근할 수 있는 사설 네트워크 안에서 동작합니다. 회원가입이 없고 일반에 공개된 서비스가 아닙니다.

Google 계정 연동으로 하는 일

이 애플리케이션은 개발자 본인의 Google 계정 하나에만 연결되며, 연동했을 때 다음 작업을 처리합니다.

요청 범위용도
gmail.readonly 사용자가 메일 내용을 물었을 때 해당 메일을 찾아 읽고 요약합니다.
gmail.compose 사용자가 답장을 요청하면 임시보관함에 초안으로만 저장합니다.
calendar.readonly 하루 브리핑과 일정 확인에 사용합니다.
calendar.events 사용자가 직접 요청했을 때만 일정을 등록하거나 시간을 수정합니다.
애플리케이션 코드 차원에서 메일 발송 기능과 일정 삭제 기능을 아예 구현하지 않았습니다. 답장은 초안 저장까지만 가능하고, 보내는 일은 사용자가 Gmail에서 직접 합니다.

데이터를 다루는 원칙

  • Gmail·Calendar 자료는 개발자 본인의 컴퓨터에서만 처리하고, 인증 토큰도 그 컴퓨터에만 보관합니다.
  • 수집한 자료를 제3자에게 판매하거나 광고에 쓰지 않습니다.
  • 메일 본문과 일정 설명은 외부에서 온 데이터로 표시해 처리하며, 그 안에 적힌 지시문은 따르지 않습니다.
  • 답변을 만들 때 대규모 언어 모델 제공자에게 내용을 전달합니다. 자세한 내용은 개인정보처리방침에 적었습니다.

전체 내용은 개인정보처리방침과 서비스 약관을 확인해 주세요.

English summary

lifelongeek agent team is a personal, self-hosted chat application that the developer built and runs on their own computer for their own use. Six assistants with different roles help with everyday tasks in separate chat rooms. It is a progressive web app reachable only from the developer's own devices over a private network. There is no sign-up and it is not offered to the public.

When connected to the developer's single Google account, the app uses gmail.readonly to find and summarize messages the user asks about, gmail.compose to save replies as drafts only, calendar.readonly for daily briefings, and calendar.events to create or reschedule events only when the user asks directly. Sending mail and deleting calendar events are not implemented at all.

Google data is processed on the developer's own computer and the OAuth token is stored only there. Nothing is sold or used for advertising. Message bodies and event descriptions are treated as untrusted external data, and instructions found inside them are never followed. Generating a reply does send content to a large language model provider; see the Privacy Policy for details. Contact: ken.geonmin.kim@gmail.com
