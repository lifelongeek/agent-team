이 방침은 개인이 만들어 개인 컴퓨터에서 운영하는 애플리케이션 lifelongeek agent team(이하 "이 앱")에 적용됩니다.

2. 요청하는 권한과 사용 목적

이 앱은 아래 네 가지 범위만 요청하며, 각 범위를 아래 목적 외에는 사용하지 않습니다.

범위사용 목적
gmail.readonly 이용자가 메일에 대해 물었을 때 해당하는 메일을 검색해 읽고 요약하거나, 답장 초안을 쓰기 전에 원문을 확인합니다.
gmail.compose 이용자가 답장을 요청하면 Gmail 임시보관함에 초안으로 저장합니다. 발송은 하지 않습니다.
calendar.readonly 하루 브리핑과 일정 조회 응답을 만듭니다.
calendar.events 이용자가 직접 등록·수정을 요청한 경우에만 일정을 만들거나 고칩니다.
더 넓은 권한(gmail.send, gmail.modify, 일정 삭제 등)은 요청하지 않으며, 해당 기능 자체를 구현하지 않았습니다.

3. 처리하는 정보

  • Gmail — 이용자의 질문과 관련된 메일의 보낸사람·제목·날짜·본문 일부(스레드당 최대 12,000자)
  • Google Calendar — 조회 기간에 해당하는 일정의 제목·시간·장소·설명
  • 계정 식별 정보 — 연결된 Google 계정의 이메일 주소(화면에 연결 상태를 보여주기 위해)
  • OAuth 토큰 — 액세스 토큰과 갱신 토큰

이 앱은 광고 식별자, 위치 정보, 연락처 목록을 수집하지 않습니다.

4. 보관 위치와 기간

  • 모든 자료는 운영자의 개인 컴퓨터(macOS) 안에서만 처리합니다. 외부 서버나 클라우드 데이터베이스에 저장하지 않습니다.
  • OAuth 토큰은 data/google/token.json 파일에 소유자만 읽고 쓸 수 있는 권한(0600)으로 저장합니다.
  • 메일 본문과 일정 내용은 답변을 만드는 동안에만 사용하며, 별도의 사본을 보관하지 않습니다. 화면에 남는 대화 기록에는 에이전트가 만든 답변 글이 포함되고, 이는 같은 컴퓨터의 로컬 데이터베이스에 남습니다.
  • 이용자가 설정 화면에서 연결 해제를 누르면 토큰 파일을 즉시 삭제합니다. Google 계정의 보안 → 타사 앱 액세스에서도 권한을 철회할 수 있습니다.
  • 대화 기록은 이용자가 로컬 데이터베이스 파일을 지우면 함께 사라집니다.

Privacy Policy (English)

1. Operator and scope

This policy covers lifelongeek agent team, a personal application built and operated by an individual on their own computer. Operator and developer: Geonmin Kim (ken.geonmin.kim@gmail.com). The app is not offered to the public, has no sign-up, and its only user is the operator, connected to a single Google account — the operator's own.

2. Scopes requested and why

The app requests only four scopes and uses each one solely for the stated purpose. gmail.readonly: find, read and summarize messages the user asks about, and read the original thread before drafting a reply. gmail.compose: save a reply as a draft in Gmail; nothing is ever sent. calendar.readonly: produce daily briefings and answer schedule questions. calendar.events: create or reschedule an event only when the user directly asks. Broader scopes such as gmail.send, gmail.modify or calendar deletion are not requested, and those features are not implemented at all.

3. Information processed

Gmail: sender, subject, date and part of the body (up to 12,000 characters per thread) of messages relevant to the user's question. Google Calendar: title, time, location and description of events in the requested range. Account identifier: the connected account's email address, shown to indicate connection status. OAuth tokens: access and refresh tokens. The app collects no advertising identifiers, no location data and no contact lists.

4. Storage and retention

Everything is processed on the operator's own macOS computer; nothing is stored on an external server or cloud database. OAuth tokens are written to data/google/token.json with owner-only permissions (0600). Message bodies and event contents are used only while composing an answer and are not copied elsewhere; the on-screen chat history retains the agent's written answer in a local database on the same computer. Pressing Disconnect in the settings screen deletes the token file immediately, and access can also be revoked at Google Account → Third-party access. Chat history disappears when the user deletes the local database file.

5. Third parties

Google user data is never sold, never used for advertising, and never used for credit assessment or anything similar.

Transfer to a language model provider. To compose an answer, the user's question and the related mail or calendar content are sent to a large language model provider's API. This transfer happens only to produce the answer the user asked for. Google user data is not used to develop or train generalized artificial intelligence or machine learning models; the API is called under terms where submitted content is not used for model training. No other third party receives Google user data. The only human who reads message contents is the operator, on their own screen.

6. Google API Services User Data Policy

lifelongeek agent team's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Safeguards

The app itself is not reachable from the public internet; it is served only inside the operator's private network, over HTTPS. Message bodies and event descriptions are handled as untrusted external data, and instructions embedded in them are never followed. Creating or changing a calendar event runs only when the user's own message contains a request to do so, so mail content cannot cause a schedule change. Token and push-notification key files are stored with owner-only permissions (0600).

8. User rights

The user may disconnect and delete stored data at any time. Requests to access, correct or delete data: ken.geonmin.kim@gmail.com

9. Changes

If this policy changes, this page is updated along with the effective date below.
